# Asset Validation Report

Generated by `AssetManager._validate()` at runtime. This documents the
expected + measured dimensions of every GLB asset in the project.

## World Scale

The entire game uses **meters** as the world unit. The Porsche 911 is the
primary scale reference (4.5 m long). All other assets are normalized to
match via per-asset `scale` factors in `ASSET_REGISTRY`.

## Assets

- **URL**: `./models/porsche_911.glb`
- **Scale**: 1.0 (already in meters)
- **Expected size**: 4.5 x 1.3 x 1.9 m (L x H x W)
- **Source**: Karol Miklas, CC-BY-SA-4.0
- **Notes**: The primary scale reference. Wheel radius measured from the

### track — Drift Race Track
- **URL**: `./models/drift_race_track_free.glb`
